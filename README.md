# SimpleFaceDetection

A beginner-friendly computer vision project exploring object detection and real-time face detection using Python, OpenCV, and YOLO.

This project follows the Python Simplified tutorial and documents my learning process, implementation, and experiments.

## Tutorial Reference

- **Creator:** Python Simplified
- **Tutorial:** [Python Face Detection from Scratch (OpenCV + YOLO + Webcam)](https://www.youtube.com/watch?v=GhAC0xBIepQ&list=PLqXS1b2lRpYSs1X7jdyFTqfrQDQanJ7X8&index=4)

The original tutorial creator and the community model authors deserve credit for their respective work.

## Project Contents

- Image-based object detection
- Face detection using a YOLO face model
- Webcam-based real-time detection
- Experiments with GPU acceleration using CUDA
- Jupyter notebooks documenting the learning process

## Technologies

- Python
- OpenCV
- Ultralytics YOLO
- Jupyter
- PyTorch and CUDA, where supported

## Setup

1. Install a compatible Python environment.
2. Install the required dependencies.
3. Download the model weights from their original sources, subject to their respective licenses.
4. Open the notebooks and follow their instructions.

Detailed setup and CUDA instructions will be added after testing the environment.

## Learning Goals

- Understand object detection versus face detection
- Process images and webcam frames with OpenCV
- Run YOLO inference
- Explore CPU and GPU inference
- Organize and document a computer vision project
