# Models

This directory is reserved for pretrained and custom computer vision model weights used in this project.

## Model Sources

| Model | Purpose | Source |
|---|---|---|
| YOLOv8 | General object detection | [Ultralytics](https://github.com/ultralytics/ultralytics) |
| YOLO Face | Face detection | [akanametov/yolo-face](https://github.com/akanametov/yolo-face) |

## Notes

- Model weights are not tracked in Git.
- Download model weights from their original sources.
- Check model compatibility and licensing before use.
- Keep model filenames consistent with the notebook configurations.
